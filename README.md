# MindHub

MindHub is a mobile social platform designed to give university students a space to share experiences, discuss personal challenges, and find support.

## Features

- Student and psychologist authentication
- Topic-based posts and discussions
- Public and anonymous/private posting
- Comments and community interaction
- User profiles and profile editing
- Psychologist discovery and profile pages
- Categories for academic, psychological, addiction, family, and relationship topics
